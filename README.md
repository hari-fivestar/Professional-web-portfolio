Hari Krishna Portfolio Website

This is my personal portfolio website, designed and developed using HTML, CSS, and JavaScript.  
It serves as an online resume that showcases my skills, projects, and contact information, built with a focus on clean design, responsiveness, and smooth animations.

---

Features

Home Section – Introductory banner with name, role, and resume download link. 
About Section – Brief overview of academic background and career goals.  
Projects Section – Displays details of various full-stack and web projects.  
Skills Section – Highlights key skills in front-end, back-end, and programming.  
Contact Section – Provides phone and email details for professional connections.  
Smooth Animations – Typing effects, fade-ins, hover transitions, and glow effects.  
Responsive Design – Works across desktops, tablets, and mobile screens.
